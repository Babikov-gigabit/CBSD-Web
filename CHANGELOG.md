# Изменения

## Не выпущено

ISO-образы:
- Загрузка ISO из браузера в `<workdir>/src/iso/upload` с прогрессом,
  отменой и проверкой SHA-256; скачивание ISO сервером по ссылке как
  фоновая задача. Образ регистрируется в CBSD (`cbsd media mode=register`).
- Поле «Установочный ISO» в форме создания ВМ bhyve/Xen: ВМ ставится
  с выбранного образа вместо ISO профиля.
- Удаление загруженных образов, не подключённых к ВМ.
- Новые настройки `iso_max_size_gb` и `iso_fetch_allow_private`.
- Носители читаются из `storage_media.sqlite` (так их хранят текущие версии
  CBSD), а не только из `local.sqlite`.

## 0.2.1 — 2026-10-27

Снимки ZFS:
- «Открыть отдельно»: старый снимок запускается рядом как новая клетка
  (клон ZFS через `jcreate zfs_snapsrc=`, создаётся мгновенно, без копирования).
  Исходная клетка, её текущее состояние и все снимки остаются как есть;
  чтобы вернуться, достаточно удалить новую клетку. По желанию перед этим
  делается снимок текущего состояния.
- «Управление откатами»: таблица всех прошлых откатов, из которой можно
  выборочно убрать записи со схемы; у каждой линии отката на схеме есть ✕.
  Меняется только журнал веб-интерфейса, ZFS не затрагивается.
- Удалённые клетки-копии больше не остаются на схеме.
- При откате галочка «сохранить текущее состояние как ветку» по умолчанию
  выключена.

Сборка:
- Версия берётся из `cmd/cbsd-web/main.go` в Makefile и `install.sh`.

## 0.2.0

- Полные настройки клеток (около 70 параметров `jset`) и лимиты rctl.
- Терминал клетки в браузере (`jlogin`), консоль VNC для ВМ в браузере.
- Сеть, трафик, процессы и диск окружения на вкладке «Параметры».
- Снимки ZFS: расположение, схема с ветками и историей откатов, откат
  с остановкой и запуском клетки, клонирование работающей клетки.
- `install.sh` всегда пересобирает из исходников.
